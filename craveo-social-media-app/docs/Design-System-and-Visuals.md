# Craveo ~ Design System & Visual Foundations

This document defines the visual language and UI foundations for the Craveo Food Social Media App.
It ensures consistency between design (Figma) and implementation (Next.js frontend).


### **1. Design Philosophy**

Craveo prioritizes:
- Food-first content
- Visual clarity
- Minimal distraction
- Familiar social interactions

The UI avoids clutter and emphasizes imagery, engagement, and readability.


### **2. Screen Sizes & Breakpoints**

### Mobile (Primary)
- Width: 390px
- Approach: Mobile-first
- Used for all initial designs

### Desktop (Secondary)
- Width: 1440px
- Max content width: 1200px
- Centered feed layout

### 3. Color System

**Core Brand Colors**

### 5. Figma Component Strategy

- Colors are stored as **styles**
- Components are reusable:
  - PostCard
  - Action buttons
  - Inputs
- Layouts are designed once and reused


### 6. Consistency Rules

1. Never use raw hex values in components
3. Green = Engagement, trust & confirmation
4. Maintain WCAG AA contrast
5. Same button meanings across screens
