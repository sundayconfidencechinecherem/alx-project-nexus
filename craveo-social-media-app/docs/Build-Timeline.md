# Craveo – Build Timeline

This document outlines the planned and actual development milestones for the Craveo Food Social Media App.

- **Start Date:** Jan 19, 2026  
- **End Date:** Jan 29, 2026  
- **Total Duration:** 10 days

### Notes

- Each task will have a corresponding **GitHub Issue** to track progress.  

- Commits will follow **clear semantic messages**, 

 **E.g:**

`feat: add PostCard component`, 

`fix: resolve feed loading bug`.  

- PWA support and mobile responsiveness will be added after MVP functionality is complete.  
- Challenges, lessons learned, and adjustments will be logged in 

`Challenges-And-Lessons.md`.
