
#  ALX Coffee Shop App

ALX Coffee Shop is a **mobile e-commerce application** that allows users to browse, order, and track premium coffee products in real-time. This repository contains the complete React Native application with shopping cart, order management, and notification systems.

### Overview

ALX Coffee Shop allows users to:
- Browse and explore different coffee categories and products
- Add, customize, and manage items in a shopping cart
- Place orders and track their status in real-time
- Receive notifications for order updates and promotions
- View order history and reorder favorite items

The app focuses on **seamless shopping experience** and **real-time order tracking** across iOS, Android, and Web platforms.

### Technologies

**Frontend:**
- React Native (Expo framework)
- TypeScript
- Expo Router (file-based navigation)
- React Context API (state management)

**Styling & UI:**
- React Native StyleSheet
- @expo/vector-icons
- Custom design system

**Storage & Performance:**
- AsyncStorage (local persistence)
- Optimized image loading
- Real-time state updates

### Key Features

- **Product Catalog** - Browse coffee categories with detailed product information
- **Shopping Cart** - Add, remove, and manage items with quantity control
- **Order Tracking** - Real-time status updates with progress visualization
- **Notifications** - Instant updates on order status changes
- **Session Persistence** - Cart and preferences saved between sessions
- **Responsive Design** - Optimized for mobile, tablet, and web

### Getting Started

```bash
# Clone the repository
git clone https://github.com/sundayconfidencechinecherem/alx-coffee-shop.git
cd alx-coffee-shop

# Install dependencies
npm install

# Start the development server
npx expo start
```
